# BioWell — Student Wellness CLI

## About
BioWell is a simple Python command-line project designed
to encourage healthy study habits and student well-being.

## Features
- Guided breathing exercise
- Study break suggestions
- Daily wellness tips
- Simple menu-driven interface

## Technology Used
- Python 3

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   python BioWell.py

## Project Objective
To use basic programming skills to create a useful
student wellness tool as part of a Digital Skills
and Life Skills practical.
